# Vestara showcase — evidence and scope

Snapshot: 14 October 2026. This is a visual development retrospective, not a gameplay audit or production readiness certification.

## Sources

- `canary-3.6.1/canary-3.6.1/docs/systems/attributes/README.md`: seven attributes, five points from level 2, rewarded-level high-water mark.
- `canary-3.6.1/canary-3.6.1/docs/systems/masteries/README.md`: mastery persistence, allocation, runtime hooks and client bridge. Exact ranks/rosters intentionally not presented as final balance.
- `canary-3.6.1/canary-3.6.1/docs/systems/affixes/README.md`: rarity, persisted rolls, equipment aggregation and combat integration.
- `canary-3.6.1/canary-3.6.1/docs/systems/item-lock/README.md`: vendor, destructive forge and configurable ground-drop protection. Not a claim of universal loss prevention.
- Conversation: user confirmed affixed-item market trading, Spell Echo and sequential ricochet functioning. Market and combat were not re-tested for this showcase.
- `art-output/set-concepts/README.md`: 83 proposals; opening update mentions a generic framework, while the older closing sentence still says none exists. Showcase distinguishes framework from proposed set catalogue and does not claim deployed bonuses.
- `art-output/dungeon-ui/README.md`: functional browser design prototype with simulated queue, reuseable assets, and client HTML/CSS implementation direction. Screenshot captured locally for this showcase.
- Conversation: Albion/Camelot/Arthur/Merlin/Zathroth arc and the three raid progression tiers are design direction. The local `docs/design/ALBION_MOONSILVER_STORY.md` is only one byte in this checkout, so it was not treated as evidence. Proposed dialogue is quoted from the user’s discussion.
- Conversation and asset handoffs: boost items, status icons, Pocket Portal, monsters and magical effects. Artwork existence is not gameplay readiness.

`asset-manifest.json` records every copied image's original path, dimensions, animation frame count and SHA-256. All image copies are unchanged. The page scales previews with CSS; it does not modify import art, sprite sheets, catalogs or gameplay. Preview GIF/WebP files may be montage/composited studies; they are not import sprites. Creature display names are editorial labels, not verified live server monster IDs. The Judicator used in raid progression is an illustration, not a final angel-boss appearance.

No new rights to Tibia source assets are implied. Do not distribute this development pack as a standalone unrestricted art library.
